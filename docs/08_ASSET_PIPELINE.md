# 08 · Asset Pipeline & Licensing

> **From the brief:** "You will create ALL Art/Assets yourself or source free to use / CC0 and commercial safe assets. Make sure they are HIGH quality and amazingly outstanding."
> **Strategy: procedural-first.** Everything the game needs *can* be generated by our own code (3D props, characters, creature art, card frames, packs, covers, textures, icons, SFX, voices). Carefully chosen **CC0** packs are **optional enhancements**, used only where they clearly beat what we generate. This keeps the game license-clean, tiny to download, consistent in style, and easy to restyle.

---

## 1. License Policy (non-negotiable)

| Allowed | Notes |
|---------|-------|
| **Self-made** (code-generated or hand-authored SVG/GLSL) | Preferred. We own it |
| **CC0 / Public Domain** | Keep the original license file in `assets-src/<pack>/`. Credit anyway (courtesy) |
| **OFL-1.1** | Fonts only (via `@fontsource`) |
| **MIT / ISC / Apache-2.0** | Code libraries and icon sets (Lucide ISC, Phosphor MIT) |

| Not allowed | Why |
|-------------|-----|
| CC-BY-SA, any **NC** (non-commercial) or **ND** (no-derivatives) | Commercial-unsafe or viral |
| CC-BY | **Only** with explicit user approval, and credited in-game and in `CREDITS.md` |
| GPL/LGPL code or assets | Viral license (note: popular holo-card CSS demos are GPL. **Do not copy**) |
| "Free for personal use", unclear licenses, ripped or fan assets, real brand logos, AI images with unclear rights | Legal risk |

Every non-self-made asset gets a **`CREDITS.md`** row (name, author, source URL, license, files, date) **in the same commit** that adds it. The in-game Credits screen is generated from `src/content/credits.ts`.

## 2. ⚠️ Network Access in the Cloud Dev Environment

As of 2026-09-26, the Claude Code cloud environment used for this project **blocks** (HTTP 403 by egress policy) all the usual CC0 asset hosts:
`kenney.nl` · `quaternius.com` · `poly.pizza` · `polyhaven.com` · `dl.polyhaven.org` · `ambientcg.com` · `opengameart.org` · `itch.io` (+ `*.itch.zone` downloads) · `freepd.com` · `freesound.org` · `sketchfab.com` · `archive.org` · `fonts.google.com` · `cdn.jsdelivr.net`.
**Reachable:** the npm registry (fonts through `@fontsource`, libraries) and GitHub.

**Options (see Q30):**
1. **Procedural-only** (works today, the default plan).
2. The user **adds these domains** to the environment's allowed network domains (cloud environment settings → Network access), so CC0 packs can be downloaded by scripts.
3. The user **downloads packs manually** and commits them to `assets-src/` (with their license files).
4. Use **GitHub-hosted CC0 mirrors** (verify the license in the repo) via attaching the repo to the session.

## 4. Art Override System (for future custom art)
The art resolver looks for overrides first, so **any** generated art can be replaced later without code changes:
```
public/art/overrides/cards/<cardId>.webp        # e.g., gk.emberdawn.112.webp
public/art/overrides/species/<speciesId>.webp   # default art for all cards of a species
public/art/overrides/packs/<productId>-<variant>.webp
public/art/overrides/manga/<volumeId>.webp
```
Overrides must be user-owned or properly licensed (documented in `CREDITS.md`).

## 5. Formats & Budgets

| Type | Format | Budget | Tooling |
|------|--------|--------|---------|
| Card art (window / full) | WebP (q≈80) | ≤ 30 KB / ≤ 70 KB | `sharp` |
| UI images and textures | WebP / AVIF, or procedural | ≤ 100 KB each | `sharp` |
| Vector art | SVG (optimized) | ≤ 20 KB each | SVGO |
| 3D models (if any CC0) | GLB, meshopt-compressed, KTX2 textures | ≤ 200 KB each | `@gltf-transform/cli` |
| Music | OGG (Vorbis/Opus) + MP3 fallback, 128–160 kbps | ≤ 3 MB per track | ffmpeg (dev machine) |
| SFX (sampled) | OGG + MP3 sprite sheets | ≤ 300 KB per sprite | ffmpeg / audiosprite |
| Fonts | WOFF2 subsets | ≤ 60 KB per family | `@fontsource` |

**Download strategy:** the core boot (UI, fonts, first set's art thumbnails, day music) stays under 8 MB. Everything else is lazy-loaded and cached by the service worker.

## 6. Folder Layout & Naming
```
assets-src/                 # raw sources NOT shipped (CC0 packs with LICENSE files, SVG masters, genome notes)
public/art/v<N>/<setSlug>/<nnn>.webp          # pre-rendered card art (versioned folder = immutable cache)
public/art/v<N>/<setSlug>/manifest.json       # genomeVersion, seeds, hashes
public/art/overrides/…                        # user overrides
public/audio/v<N>/music/<track>.(ogg|mp3)
public/audio/v<N>/sfx/<sprite>.(ogg|mp3|json)
src/art/svg/…                                 # frames, icons, logos as components or strings
src/art/sdf/…                                 # GLSL shader modules
```
Names: `kebab-case`, no spaces, lowercase. Versioned folders are bumped whenever re-rendered or replaced.

## 8. Quality Bar & Review
- **Art Spike acceptance (Phase 1):** 3 creatures (Sparkit, Emberpup, Sploot) rendered in both styles on real card frames with foil. One diorama corner with a shelf, counter, lighting and one walking Peg-folk. **The user picks the direction.**
- **Checklist for any new asset:** matches the palette and shape language (`04`) · readable at thumbnail size · works in day and night lighting · has a colorblind-safe cue · within budget · licensed and credited.
- **Visual regression:** `/debug/art` and `/debug/cards` galleries get Playwright screenshots, which are reviewed on every art-engine change.
